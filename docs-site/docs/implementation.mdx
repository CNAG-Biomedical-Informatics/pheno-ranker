## Components

The core of `Pheno-Ranker` is a [Perl module](https://metacpan.org/pod/Pheno%3A%3ARanker),
accessible through a [command-line interface](/usage#synopsis). The
[Desktop App](/desktop) uses the same analysis engine through a local graphical
interface. The CLI remains available independently, including through CPAN.

:::tip[Which interface should I use?]
Use the Desktop App for guided local workflows and interactive results. Use the
[Command-Line Interface (CLI)](/usage) for terminal, server, batch, and scripted
workflows.
:::
## Utilities

`Pheno-Ranker` includes several companion command-line utilities:

1. [bff-pxf-plot](/bff-pxf-plot): a CLI tool to create summary statistics for BFF/PXF data.
2. [bff-pxf-simulator](/bff-pxf-simulator): a CLI tool to simulate BFF/PXF data.
3. [csv2pheno-ranker](/csv-import): a CLI tool to convert `CSV` into `Pheno-Ranker` input files.
4. [QR encoder/decoder](/qr-code-generator): CLI tools to transform data back and forth into QR codes and `PDF` reports.
