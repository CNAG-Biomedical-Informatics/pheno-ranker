:::tip[Choose the shortest path]
`Pheno-Ranker` reads BFF and PXF directly. Convert other clinical standards to
BFF with **Convert-Pheno**. For non-clinical categorical data, use the generic
JSON/YAML or CSV workflows.
:::

<Tabs>
<TabItem value="clinical" label="Clinical standards">

For OMOP-CDM, openEHR, FHIR R4, REDCap, and CDISC data, use [Convert-Pheno](/clinical-formats) to produce BFF `individuals.json`, then run Pheno-Ranker with its built-in BFF handling.

</TabItem>
<TabItem value="yaml-json" label="YAML / JSON">

Use this path for an array of categorical JSON or YAML records that does not
follow BFF or PXF. A small configuration identifies the record ID and the fields
to compare. Nested arrays are handled automatically. Follow the
[MoviePackets tutorial](/generic-json#moviepackets) for a complete example.

</TabItem>
<TabItem value="csv" label="CSV">

We developed a utility that converts `CSV` files to `JSON` and automatically creates the **configuration file** needed. See an example on how to use it [here](/csv-import).

</TabItem>
</Tabs>
