**BFF** stands for **B**eacon **F**riendly **F**ormat. The [BFF](https://b2ri-documentation.readthedocs.io/en/latest/data-ingestion) is a data exchange format composed of 7 `JSON` files. These files correspond to the 7 entities of the [Beacon v2 Models](https://docs.genomebeacons.org/models).

:::info[About Beacon v2 Models' entities]
Of the seven entities (a.k.a., entry types) in the Beacon v2 Models, [individuals](https://docs.genomebeacons.org/schemas-md/individuals_defaultSchema) is typically the only one that contains phenotypic data (represented at **record-level** granularity).
:::
`Pheno-Ranker` accepts data from the [individuals](https://docs.genomebeacons.org/schemas-md/individuals_defaultSchema) entity, serialized in [BFF](https://b2ri-documentation.readthedocs.io/en/latest/data-ingestion) format (`individuals.json`).

## Run This Format

<Tabs defaultValue="desktop" groupId="interface">
<TabItem value="desktop" label="Desktop">

1. Select **New analysis**, then choose cohort or patient mode.
2. Open **User files** and select `individuals.json` as the reference cohort.
3. In patient mode, also select the target record.
4. Select **Run analysis**.

No configuration file is required. See the [Desktop guide](/desktop) for the
visual workflow.

</TabItem>
<TabItem value="cli" label="CLI">

For cohort mode:

```bash
pheno-ranker -r individuals.json
```

For patient mode:

```bash
pheno-ranker -r individuals.json -t patient.json
```

The commands create `matrix.txt` and `rank.txt`, respectively. Continue with
[Cohort Mode](/cohort), [Patient Mode](/patient), or the full [CLI Reference](/usage).

</TabItem>
</Tabs>

<details>
<summary>How are BFF arrays compared?</summary>

For first-level BFF arrays such as `diseases`, `exposures`, `interventionsOrProcedures`, `measures`, `phenotypicFeatures`, and `treatments`, `Pheno-Ranker` replaces numeric array indexes with semantic identifiers configured in `identity_paths`.

From v1.08 onward, users do not need to transpose or manually rewrite nested BFF arrays. Nested arrays are canonicalized automatically from their meaningful content, so equivalent nested objects can match even if their order differs between records.

</details>
