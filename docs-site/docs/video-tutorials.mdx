Short demonstrations of **Pheno-Ranker Desktop**, recorded with version 1.09
using the bundled examples.

[Watch the Desktop tutorial playlist on YouTube](https://www.youtube.com/playlist?list=PLErogZfEae0M).

## Tutorials

| Video | What it shows |
| --- | --- |
| Overview | Why compare records, the two analysis modes, and the Desktop workspace |
| Cohort mode | Compare all pairs and explore a heatmap, dimensionality reduction plots, and a filtered network |
| Patient mode | Rank reference records against a target and inspect shared and different features in a pair comparison |

For installation and written instructions, start with the [Desktop guide](/desktop).
