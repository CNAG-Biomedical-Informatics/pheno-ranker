Pheno-Ranker reads [Beacon v2 Models (BFF)](/bff) and [Phenopackets v2 (PXF)](/pxf) directly. For other structured clinical standards, use [Convert-Pheno](https://cnag-biomedical-informatics.github.io/convert-pheno/) to normalize the source data to BFF before comparison.

:::info[Why convert first?]
Clinical standards encode identity, terminology, and repeated events differently. Convert-Pheno owns those source-specific mappings and groups the data into individual-level BFF records. Pheno-Ranker can then use its built-in BFF configuration and canonicalization instead of treating clinical JSON as an arbitrary structure.
:::

## Run This Format

First use Convert-Pheno to produce BFF `individuals.json`. Then run that BFF
output in Pheno-Ranker; no source-format configuration is required.

<Tabs defaultValue="desktop" groupId="interface">
<TabItem value="desktop" label="Desktop">

1. In Convert-Pheno, convert the clinical source to Beacon v2/BFF.
2. In Pheno-Ranker Desktop, select **New analysis** and choose cohort or patient mode.
3. Under **User files**, select the generated `individuals.json` as the reference.
4. In patient mode, also select a target record, then select **Run analysis**.

</TabItem>
<TabItem value="cli" label="CLI">

For cohort mode:

```bash
pheno-ranker -r individuals.json
```

For patient mode:

```bash
pheno-ranker -r individuals.json -t target.json
```

Continue with [Cohort Mode](/cohort), [Patient Mode](/patient), or the full
[CLI Reference](/usage).

</TabItem>
</Tabs>
